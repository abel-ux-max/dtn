# DTN – landing page

Link page for DTN and the EP *Eschatology*.

```
index.html        page markup
css/style.css     all styles (colours and fonts are set at the top in :root)
js/main.js        copy button for the booking email
img/              logo, bird, bone-pile ground, background wash, icons
```

Open `index.html` in a browser to view it. To put it online, upload the whole folder
as-is to any static host (Netlify, GitHub Pages, Cloudflare Pages, or regular web hosting).

Fonts load from Google Fonts: IM Fell English SC (title) and Special Elite (links and text).

## Visitor stats (GoatCounter)

The page counts visits and link clicks with GoatCounter, which uses no cookies and stores no
personal data, so no cookie banner is needed.

1. Sign up at https://www.goatcounter.com and pick a code, e.g. `dtnband`.
2. In `index.html`, near the bottom, replace `YOURCODE` with that code.
3. Visits show up in your GoatCounter dashboard. Link taps appear under names like
   `instagram`, `spotify` and `booking-email`.

Stats only work on the live site, not when opening the file from your computer.
